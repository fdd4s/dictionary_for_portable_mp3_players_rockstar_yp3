# dictionary tools for portable mp3 players rockstar yp3

## What it does

Tools to handle Shenju YP3 Rockstar portable mp3 players dictionary format, each dictionary it has 3 files, one for words index "dict.id", one for words meaning "dict.txt", and one for pronounciation of each word in Signed 16bits PCM audio mono 10k Sampling rate format "dict.pcm".  

## Where to get dictionaries

For now it's only available one dictionary English/Chinese in Shenju Portable Player Dictionary Format.  

http://www.eroshifi.com/upload/aigo/aigo_MP3-803(%E5%AD%A6%E4%B9%A0%E7%89%88)%E8%AF%8D%E5%85%B8%E6%96%87%E4%BB%B6.zip
  
But improving these tools it could add new dictionaries with data from StarDict, Apertium and Wiktionary projects.

## How to load the dictionary in the player

The dictionary must be in the folder "dict" of root folder of the sdcard.  
And it must have 3 files: dict.id dict.pcm dict.txt
